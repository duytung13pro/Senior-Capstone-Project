# User Documentation

This section  is written for the people who will actually use the system, teachers and students, instead of developers.

## At a Glance

The platform supports:

- Teacher workflows such as class management, lesson plans, assignments, attendance, announcements, messages, and profile settings
- Student workflows such as joining classes, viewing assignments, checking grades, reading announcements, accessing resources, and reviewing progress
- Role-based access so different dashboards appear after login

## Start Here

- Read the [Sign Up Guide](./signup-guide.md) first.
- Use the [User Manual](./user-manual.md) when you need detailed task instructions.
- Check the [FAQ](./faq.md) when something is unclear or not working as expected.
