# User Manual

This manual is a reference document for day-to-day use of the Senior Capstone Project platform.

## System Overview

The application provides role-based dashboards:

- Teachers manage courses, lesson plans, assignments, attendance, and communication
- Students review coursework, join classes, and track their progress
- Admin users have a separate dashboard for administration

## Navigation Reference

### Teacher Sidebar

Teacher users can access:

- `Dashboard`
- `My Classes`
- `Lesson Plans`
- `Assignments`
- `Student Progress`
- `Attendance`
- `Messages`
- `Announcements`
- `Resources`
- `Productivity Tools`
- `Profile & Settings`

### Student Sidebar

Student users can access:

- `Dashboard`
- `My Classes`
- `Available Classes`
- `Assignments`
- `Messages`
- `Grades`
- `Schedule`
- `Analytics`
- `Progress`
- `Resources`
- `Profile`

## Teacher Tasks

### Manage Classes

Purpose:
View class information and move into class-specific actions.

How to use it:

1. Open `My Classes`.
2. Select a class from the list.
3. Review the class page.
4. Use the page to inspect resources and assignment-related actions.

### Create Lesson Plans

Purpose:
Prepare structured instructional content for a class.

How to use it:

1. Open `Lesson Plans`.
2. Create a new lesson plan.
3. Enter the lesson title and instructional details.
4. Save the lesson plan.
5. Open the detail page when you need to review or update it.

### Create Assignments

Purpose:
Publish work for students to complete.

How to use it:

1. Open `Assignments`.
2. Select `Create Assignment`.
3. Choose the class.
4. Enter the assignment title.
5. Add instructions and any needed details.
6. Set a due date if required.
7. Publish the assignment.

### Review Student Progress

Purpose:
Track individual or class-level learning progress.

How to use it:

1. Open `Student Progress`.
2. Choose a class.
3. Open a specific student record if needed.
4. Review the displayed progress information.

### Record Attendance

Purpose:
Mark attendance for a selected class and date.

How to use it:

1. Open `Attendance`.
2. Select a class.
3. Choose the attendance date.
4. Mark student attendance.
5. Save the changes.

### Send Messages

Purpose:
Communicate with students through the built-in messaging area.

How to use it:

1. Open `Messages`.
2. Select or create a conversation.
3. Write your message.
4. Send it.

### Post Announcements

Purpose:
Share class-wide updates.

How to use it:

1. Open `Announcements`.
2. Create a new announcement.
3. Enter the title and message.
4. Publish it for the class.

### Manage Resources

Purpose:
Provide supporting files or learning materials.

How to use it:

1. Open `Resources`.
2. Add or review shared materials.
3. Remove outdated resources if needed.

### Use Productivity Tools

Purpose:
Support teacher planning and communication workflows.

How to use it:

1. Open `Productivity Tools`.
2. Review the available templates and planning options.
3. Choose the tool that matches your current task.

### Edit Profile And Settings

Purpose:
Keep your account information current.

How to use it:

1. Open `Profile & Settings`.
2. Update profile fields such as name, phone, location, bio, or avatar.
3. Review notification and preference settings.
4. Save changes.

## Student Tasks

### Enroll In A Class

Purpose:
Join a class that is available for students.

How to use it:

1. Open `Available Classes`.
2. Select a class.
3. Review the class details.
4. Enroll if the class is open.

### View Class Content

Purpose:
Access learning materials from enrolled classes.

How to use it:

1. Open `My Classes`.
2. Select a class.
3. Review announcements, lessons, assignments, and resources.

### Read Lesson Plans

Purpose:
Follow the current learning sequence.

How to use it:

1. Open an enrolled class.
2. Go to the lessons section.
3. Open the lesson you want to read.

### Complete Assignments

Purpose:
Stay on top of coursework and deadlines.

How to use it:

1. Open `Assignments`.
2. Review open assignments.
3. Open the assignment details.
4. Submit work if the page supports submission.
5. Return later to review grading status.

### Check Grades

Purpose:
Monitor academic performance.

How to use it:

1. Open `Grades`.
2. Review available scores and class performance information.

### Review Schedule

Purpose:
Track upcoming academic work.

How to use it:

1. Open `Schedule`.
2. Review events, deadlines, or assignment dates.

### Monitor Analytics And Progress

Purpose:
See study activity, learning streaks, and overall progress.

How to use it:

1. Open `Analytics` or `Progress`.
2. Review summary metrics and progress indicators.

### Read Messages

Purpose:
Stay informed about teacher communication.

How to use it:

1. Open `Messages`.
2. Read current messages.
3. Respond if the feature allows replies.

### Access Resources

Purpose:
Find class materials in one place.

How to use it:

1. Open `Resources`.
2. Search or filter materials.
3. Open the resource you need.

### Update Profile

Purpose:
Keep account details accurate.

How to use it:

1. Open `Profile`.
2. Edit your personal details.
3. Save changes.

## Known Usage Notes

- Teacher and student features are separated by role, so users only see the tools for their account type.
- Some pages use Vietnamese labels, especially in authentication screens.
- The platform appears to be under active development, so interface details may continue to evolve.
