# Fair Poster

This folder contains a fair-ready poster draft for the Senior Capstone Project.

## Files

- [fair-poster.html](./fair-poster.html) printable poster layout

## How To Use It

1. Open `fair-poster.html` in a browser.
2. Review the text and replace any placeholder links before the fair.
3. Print the page directly or export it as PDF.
