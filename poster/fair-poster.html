Rewood: An AI-Assisted Learning Management System for Teachers and Students

A classroom platform designed to reduce administrative overhead for educators while giving students a clear, role-based place to access assignments, lessons, resources, messages, and progress.

Advisor

Lee Seokki

Problem

Teachers often manage classes, lessons, attendance, announcements, and student communication across disconnected tools. Students then face a fragmented experience when they need to find materials, due dates, and messages quickly.

Our Goal

Build one platform that keeps classroom organization simple, role-aware, and easy to navigate for everyday use.

Solution

1. Sign in by role. Teachers, students, and admins are routed to the right dashboard.
2. Organize teaching. Teachers manage classes, lesson plans, assignments, attendance, and announcements.
3. Support learning. Students view class content, track grades, monitor progress, and access shared resources.

Key Features

  • Role-based authentication and dashboard routing
  • Teacher portal for classes, lesson plans, assignments, messages, and attendance
  • Student portal for enrolled classes, grades, schedule, analytics, and resources
  • Centralized communication through announcements and messages
  • Profile and settings management for both major user roles

Why It Matters

3 user roles
10+ teacher tools
9+ student views

Value for Teachers

Less time switching between tools and more time focused on instruction.

Value for Students

A single place to check coursework, deadlines, learning materials, and progress.

System Architecture

The project combines a modern web frontend with a backend API and a MongoDB data layer to support authentication, classroom data, assignments, and role-specific workflows.
